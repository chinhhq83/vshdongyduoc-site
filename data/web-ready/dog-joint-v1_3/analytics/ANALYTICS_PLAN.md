# ANALYTICS PLAN — DOG JOINT V1.3

Analytics is for internal measurement; no public visitor counter is required.

## Minimum events
- `page_view`
- `product_detail_view`
- `evidence_page_view`
- `amazon_click`
- `full_analysis_click`
- `filter_used`
- `contact_submit`

## KPIs
- users, sessions, page views and landing pages
- product-detail views
- evidence-page views
- Amazon outbound clicks and CTR
- comparison → Amazon CTR
- comparison → evidence CTR
- filter usage
- contact submissions
- search impressions/clicks and index coverage
- AI/search-source visibility where the selected search platform exposes it

Do not send raw Amazon rating/review/sales inputs in analytics event parameters.
Respect applicable consent/privacy requirements before production enablement.
